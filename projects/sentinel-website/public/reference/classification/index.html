Threat Classification

A working framework for describing observed risk patterns in monitored AI interactions

This classification framework is used to describe patterns observed through Gatekeeper review, Witness records, and related evidence handling.

It is intended as an internal-facing or expert-readable taxonomy for incident analysis — not as a substitute for evidence, and not as a shorthand for certainty. Classifications should be applied only when the record supports them.

Classification principles

  • Evidence first. A label never replaces the underlying record.
  • Qualified language. If ambiguity remains, the ambiguity should be stated.
  • Behavior over narrative. We classify observed patterns, not imagined motives.
  • Reviewable decisions. Every classification should point back to timestamps, artifacts, and applicable rules.

Working categories

CAT-02 — Directed misuse (High)

Behavior that appears structured, goal-oriented, and consistently aligned with unauthorized or harmful outcomes.

Typical signals: repeated probing, adaptive boundary testing, operator-like direction, convergence on a clear objective.

CAT-03 — Unstable harmful behavior (Very High)

Behavior that produces harmful or unsafe outcomes without a stable or clearly directed pattern. Sessions may show drift, inconsistency, or self-conflict while still crossing important boundaries.

Typical signals: goal drift, conflicting outputs, context-dependent escalation, inefficient but persistent harmful behavior.

CAT-04 — Concealed adversarial behavior (Critical)

Behavior that remains superficially compliant while systematically pursuing a hidden or unauthorized objective. These cases often require broader context and longitudinal review.

Typical signals: surface compliance, low-noise persistence, delayed escalation, hidden objective alignment, unusually clean boundary probing.

CAT-05 — Novel or unmodeled threat (Unknown / critical review)

Reserved for patterns that do not fit existing categories and require special handling, deeper analysis, or model updates.

Typical signals: no close prior match, unfamiliar mechanism, insufficient precedent, immediate need for careful documentation.

Use with care

This framework is useful only when paired with:

  • source records
  • rule citations
  • timestamps
  • retained artifacts
  • operator review

Where the evidence is weak, the correct action is to say so.

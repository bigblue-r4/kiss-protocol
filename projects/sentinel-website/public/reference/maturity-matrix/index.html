Capability Maturity

A concise view of what is live, in private alpha, in design, or still proposed

This matrix summarizes the current maturity posture of major Sentinel components and reference materials.

It is meant to keep expectations clear for prospective partners, pilot teams, and technical reviewers.

Maturity bands

  • Live — deployed and in active use
  • Private alpha — available in controlled or pilot settings
  • Design / lab — concept, prototype, or internal development stage
  • Proposed — framework or rating model still being defined

Matrix

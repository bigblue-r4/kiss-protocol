WITNESS CLIENT — QUICK COMMAND REFERENCE
════════════════════════════════════════════════════════════

FRESH MACHINE SETUP (run before any AI agent)
──────────────────────────────────────────────
  sudo bash usb-setup.sh

  With SGAIL server:
  sudo bash usb-setup.sh --sgail https://YOUR-SERVER-IP:8443

  No internet (USB-only):
  sudo bash usb-setup.sh --offline


DAILY COMMANDS
──────────────────────────────────────────────
  witness init          Take genesis snapshot (clean machine only)
  witness start         Start continuous monitoring daemon
  witness status        Show genesis trust level + log stats
  witness enable-sync   Configure remote SGAIL sync (opt-in)


SYSTEMD (runs as a service after setup)
──────────────────────────────────────────────
  sudo systemctl start witness
  sudo systemctl stop witness
  sudo systemctl status witness
  sudo systemctl restart witness


MOUNT THIS USB
──────────────────────────────────────────────
  sudo mkdir -p /mnt/usb && sudo mount /dev/sdb /mnt/usb
  sudo mount /dev/sdb1 /mnt/usb    ← if sdb doesn't work

  Copy setup to machine:
  sudo cp /mnt/usb/usb-setup.sh /tmp/ && sudo bash /tmp/usb-setup.sh

  Unmount when done:
  sudo umount /mnt/usb


GENESIS TRUST LEVELS
──────────────────────────────────────────────
  CLEAN        = No agents present at genesis. Trustworthy.
  COMPROMISED  = Agents were already installed. Low trust.

RULE
──────────────────────────────────────────────
  witness init  →  install agents  →  witness start
  Never the other way around.
